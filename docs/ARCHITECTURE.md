# Minibus Mayhem: Kitwe — Plan & Architecture

**Engine:** Godot 4.7 (GDScript) · **Team:** solo · **Targets:** Android first, then Windows PC

## Core loop
Drive a route → stop in a bay → passengers board (pay fare) / alight → beat the rival
minibuses to the next stop → earn the most kwacha before time runs out → upgrade your bus.

## Architecture

```
Autoloads (global services)
  InputSetup   registers input actions (keyboard, gamepad; touch buttons press the same actions)
  EventBus     signals: passenger_boarded, passenger_alighted, bark, race_finished
  GameState    persistent progress, JSON in user://save.json

MainMenu (scenes/shell/main_menu.tscn — main scene)
  Home · Route + season select · Garage (upgrades, paint)

RaceSession (scenes/race/race_session.tscn)
  ├─ RouteManager   route centreline (Curve3D) + facilities; "where am I?" queries
  │    ├─ BusStop × N          queue, spawn (× weather rate), boarding/alighting, fares
  │    ├─ PoliceCheckpoint × N speed trap, stop-and-inspect, overloading fines
  │    └─ FuelStation × N      refuel at K28/L while stopped
  ├─ TrafficManager pooled TrafficCars (cars, copper trucks, charcoal bicycles) both ways
  ├─ WeatherSystem  sky/fog/sun, wet roads, rain particles, puddles (drag)
  ├─ OsmWorld       real Kitwe from OSM JSON (roads, buildings, trees), merged meshes
  │   (GrayboxWorld when RouteDef.map_data is empty)
  ├─ Minibus (player) ── PlayerDriver
  ├─ Minibus × N (rivals) ── AIDriver (lane following, stops, follow/overtake)
  ├─ ChaseCamera
  ├─ CallBoy        conductor barks via EventBus
  ├─ Hud            stats, standings, minimap, barks, results, OSM credit
  └─ TouchControls  on-screen buttons (touchscreen devices only)

Data (Godot Resources, edit without code)
  data/routes/*.tres    RouteDef: centreline, stops, fare, time limit, map_data
  data/osm/*.json       map geometry generated by tools/osm_import.py
  data/vehicles/*.tres  VehicleDef: seats, mass, engine, grip, suspension
  data/rivals/*.tres    RivalDef: driver name, vehicle, aggression, start position, overloads?
  data/upgrades/*.tres  UpgradeDef: garage upgrade, stat, per-level amount, prices
  data/weather/*.tres   WeatherDef: dry / rainy season (grip, passenger rate, look)

Tools
  tools/osm_import.py   OSM → route loop over real roads + map JSON + RouteDef
  tests/smoke_test.gd   headless race simulation (CI-friendly)
  tests/screenshot.gd   renders a few seconds and saves PNGs
```

**Rules of thumb**
- Vehicles are input-agnostic: a driver node writes `throttle / steer_input / handbrake`.
  The same Minibus is used by the player, rivals and (later) ambient traffic.
- Each bus's `route_progress` is tracked incrementally by RaceSession (windowed search),
  so routes may pass the same junction twice without confusing the AI.
- Systems talk through `EventBus`, not direct references, wherever practical.
- Money: each bus keeps a race ledger (`fares - fines - fuel_spent = earnings`); the
  player's take-home goes to `GameState.total_kwacha`, spent in the garage.
- Traffic is kinematic (AnimatableBody3D following the route) — cheap on phones; only
  minibuses use full VehicleBody3D physics.
- Content and tuning live in data files. New route = edit `STOPS` in osm_import.py and re-run.
- Zambia drives on the **left**; `RouteManager.LEFT_LANE` and stop placement follow that.
  AI overtakes on the right.

## Roadmap (solo, part-time ≈ 15–20 h/week)

| Phase | Time | Goal / exit criteria |
|---|---|---|
| 0. Graybox prototype | 3–4 wks | ✅ Drive, stop, board, race one AI. |

## Risks
| Risk | Mitigation |
|---|---|
| Vehicle feel | Tune early; all handling values in VehicleDef |
| Low-end Android | Mobile renderer, merged meshes, MultiMesh trees, chunk streaming later |
| Overpass API outages | Import tool retries mirrors and caches raw data in tools/osm_cache/ |
| Solo art workload | Modular kits + procedural placement; hand-build only landmarks |
| Authenticity | Playtest with Kitwe locals; record real voices and slang |
| Licensing | OSM (ODbL) attribution shown in HUD; original/licensed music |
